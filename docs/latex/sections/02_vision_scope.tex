\section{Vision and Scope}

\subsection{Vision}
The goal of the project is to provide a reliable, user-friendly and scalable platform
that helps animals find permanent homes as efficiently as possible.

\subsection{In Scope}
\begin{itemize}
  \item Publishing animals for adoption
  \item Browsing and filtering animals
  \item Submitting adoption requests
  \item Administrative management of content
\end{itemize}

\subsection{Out of Scope}
\begin{itemize}
  \item Payment processing
  \item Veterinary management
  \item Multi-organization federation
\end{itemize}
