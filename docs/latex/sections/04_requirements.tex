\section{Requirements}

\subsection{Functional Requirements}
\begin{itemize}
  \item Users can view a list of animals available for adoption.
  \item Users can view detailed information about an animal.
  \item Users can submit an adoption request.
  \item Administrators can create, update and remove animals.
\end{itemize}

\subsection{Non-Functional Requirements}
\begin{itemize}
  \item The system must be SEO-friendly.
  \item The system must support mobile devices.
  \item Administrative access must be secured.
  \item Personal data must be handled in compliance with GDPR.
\end{itemize}
